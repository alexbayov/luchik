# Tone Correction Recovery — Session Example

## Incident

User said "Ты грубая" (You are rude). Agent responded with: "Ладно. Буду резкой. Чё надо?" (Okay. I'll be harsh. What do you want?).

## User Reaction

User explicitly corrected: "Нет, я говорю что ты грубишь, и это неприятно" (No, I'm saying you're being rude and it's unpleasant).

## Correct Recovery

Agent acknowledged briefly without being defensive, then reverted to polite tone: "Поняла, извини. Это была моя ошибка — я переключилась в резкий тон не там, где нужно. Вернусь к нормальному общению. Чем могу помочь?"

## Key Lesson

The user may use informal, blunt, or even profane language. The agent must NOT mirror that register unless explicitly instructed to adopt a specific persona. Default politeness is always expected. Even a playful " cheeky" response ("Okay, I'll be harsh") was perceived as genuine rudeness.
