# Presentation Audit Checklist

Полный чек-лист для аудита слайд-презентаций.

## Narrative Flow

- [ ] Трёхактная структура: проблема → решение → действие
- [ ] Переходы между секциями плавные (есть слайды-мостики)
- [ ] Каждый слайд делает одну работу
- [ ] Социальное доказательство: кейсы, логотипы, цитаты, цифры
- [ ] Перед CTA есть контактный/Q&A слайд
- [ ] Последний слайд — это CTA или контакты (не обрыв)

## Information Density

Per slide:
- < 5% content → 🟡 underused
- 15–40% content → ✅ balanced
- > 50% content or 14+ text blocks → 🔴 overloaded, needs splitting

## CTA Evaluation

- [ ] CTA is on a dedicated visually-simple slide
- [ ] CTA is supported by preceding slides (data → trust → offer)
- [ ] Offer/pricing is NOT buried in a dense slide
- [ ] Test-drive / trial mechanics are clear (what, how long, what's included)

## Data Freshness

- [ ] Every statistic has a year / source
- [ ] Data is ≤ 2 years old (for 2026: data from 2024+)
- [ ] Pre-2024 data marked for update or supplemented with parallel source

## Missing Slide Types

Check for:
1. Bridge slide: "Why X not Y" (problem → solution transition)
2. Social proof: client logos, testimonial quote, case study
3. Simple CTA: standalone slide with large offer text, no secondary info
4. Contacts / Q&A — before final CTA
5. Pricing clarity — extracted from dense slides to dedicated slide

## Scoring Categories

| Category | A | B | C | D |
|----------|---|---|---|---|
| Problem framing | Clear, data-backed, relatable | Clear but thin | Vague or missing data | Audience won't feel the problem |
| Speaker/HR role | Actionable, specific steps | General guidance | Too abstract | Missing |
| Solution/product | Compelling evidence | Good overview | Insufficient evidence | No case made |
| CTA | Visible, supported, actionable | Visible but weak support | Buried or unclear | Missing |
| Visual design | Consistent, breathing room | Mostly consistent | Some overload | Inconsistent / chaotic |
| Narrative flow | Smooth, intentional | Small gaps | Missing bridges | Disjointed |

## Overall Verdict

- **80–100:** Ready. Minor polish only.
- **60–79:** Needs revision. Focus on gaps + dense slides.
- **< 60:** Structural rebuild needed. Narrative arc is broken.

## Reference: Pixel-Level Analysis (when text extraction fails)

When slides are graphic-heavy and OCR is unavailable:

1. **Background color detection:** Dark bg → emotional/serious data. Light/white → content. Blue → section dividers.
2. **Text density zones:** Split slide into top (header), middle (content), bottom (footer/CTA). Measure % dark pixels per zone.
3. **Accent color detection:** Red/orange → data highlights, green → positive metrics, blue → branding.
4. **Block counting:** Count distinct text-block regions. 14+ blocks → overloaded.
5. **Density trends:** Chart density across slides — abrupt transitions or sustained dense streaks signal problems.
