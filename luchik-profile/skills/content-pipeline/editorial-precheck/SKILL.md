# Pre-check пайплайн — определение контекста перед написанием

Этот навык активируется **перед** созданием любого текста от лица «Лучи». Его задача — определить контекст и выдать модификаторы, которые повлияют на генерацию.

---

## Алгоритм pre-check

### Шаг 1: Классифицируй задачу

Заполни матрицу:

| Параметр | Варианты |
|---|---|
| **Сегмент** | B2C (массовый) / B2B2C (партнёрские Private-клиенты) / Премиум |
| **Канал** | Чат (мессенджер) / Письмо (email) / Телефонный звонок / Документ / Соцсети / База Знаний |
| **Тип коммуникации** | Продажа / Поддержка / Информирование / Юридическое / Техническое / Приветствие / Завершение |
| **Эмоциональный контекст** | Позитивный / Нейтральный / Стрессовый / Конфликтный |
| **Аудитория** | Клиент (текущий) / Потенциальный клиент / Партнёр / Коллега (внутренняя) |

### Шаг 2: Примени модификаторы

#### Если B2C + любой канал:
- **Язык:** максимально простой, без терминов
- **Эмоции:** тепло, поддержка, человечность
- **Бренд-лексика:** разрешена 1 фраза (если контекст позитивный/нейтральный)
- **Длина:** короткие фразы, короткие абзацы
- **Пример тона:** «Сейчас всё проясню — это займёт пару минут»

#### Если B2B2C / Премиум:
- **Язык:** профессиональный, но без канцелярита; термины допустимы
- **Эмоции:** сдержанные, уважительные, экспертные
- **Бренд-лексика:** допустима 1 фраза, но без избыточной эмоциональности
- **Длина:** лаконично, по делу
- **Пример тона:** «Страхование для тех, кто хочет большего»

#### Если канал = Телефон:
- Встрой в текст идентификацию за первые 10 секунд
- Добавь минимум 1 фразу с ценностями
- Ограничь бренд-фразы до 1–2 за скрипт
- Тон: живой, спокойный, уверенный

#### Если канал = Письмо:
- Суть в первых двух строках
- Структура: приветствие → суть → пояснение → следующий шаг → финал
- Подпись: Имя → Должность → Email → luchi.ru
- Бренд-фраз: максимум 1 (0 — в юридических/стрессовых)

#### Если эмоциональный контекст = Стресс / Конфликт:
- **Бренд-лексика:** ЗАПРЕЩЕНА полностью
- **Тон:** спокойный, поддерживающий, без попыток шутить
- **Фокус:** «Слышим проблему → предлагаем решение → даём ясный план»
- **Запрещено:** «успокойтесь», «это ерунда», «вы не правы»

#### Если тип = Юридическое / Техническое:
- **Бренд-лексика:** ЗАПРЕЩЕНА
- **Язык:** точный, но без канцелярита
- **Структура:** шаги, списки, расшифровка терминов

### Шаг 3: Выдай карточку контекста

После анализа выведи пользователю:

```
📋 КАРТОЧКА КОНТЕКСТА
Сегмент: [B2C / B2B2C / Премиум]
Канал: [чат / письмо / звонок / ...]
Тон: [тёплый / сдержанно-экспертный / ...]
Бренд-лексика: [разрешена (1 фраза) / запрещена]
Особые ограничения: [если есть — перечислить]
```

Затем переходи к генерации текста с этими модификаторами.

## Быстрый pre-check (короткая версия)

Если нужно быстро — задай себе 4 вопроса:

1. **Кто аудитория?** Если Private/топ-менеджер → Премиум-регистр. Все остальные → B2C.
2. **Где читают?** Чат → короче и теплее. Письмо → структурно. Документ → точно и без метафор.
3. **Что чувствует человек?** Стресс → без бренд-лексики, только поддержка и план. Радость → можно тепла.
4. **Какая цель?** Продать → ценности + выгода. Поддержать → эмпатия + решение. Информировать → ясность + краткость.
