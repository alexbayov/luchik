# OCR из изображений через tesseract.js (WASM, без native бинарника)

## Когда нужно
- Пользователь прислал скриншот / изображение с текстом (референс, пример поста, документ)
- Нужно извлечь текст, но `tesseract` (native binary) не установлен
- `pytesseract` установлен, но без самого tesseract не работает

## Решение: tesseract.js через Node.js

`tesseract.js` — WASM-сборка Tesseract OCR, работает в Node.js без установки системных пакетов. Поддерживает русский язык.

### Быстрый запуск

```javascript
const Tesseract = require('tesseract.js');
const imagePath = '/путь/к/изображению.jpg';

Tesseract.recognize(
  imagePath,
  'rus+eng',           // язык: русский + английский
  { logger: m => console.log(m.status, Math.round(m.progress * 100) + '%') }
).then(({ data: { text } }) => {
  console.log(text);
}).catch(err => {
  console.error('OCR Error:', err.message);
});
```

### Установка

```bash
npm install tesseract.js
```

Или если `tesseract.js` уже есть в соседнем приложении (например, Codex.app), можно использовать оттуда:

```javascript
const Tesseract = require('/Applications/Codex.app/Contents/Resources/.../tesseract.js');
```

### Параметры

| Параметр | Значение | Комментарий |
|----------|----------|-------------|
| `imagePath` | строка | Путь к изображению |
| `lang` | `'rus+eng'` | Русский + английский для смешанных текстов |
| `logger` | функция | `(m) => console.log(m.status, m.progress)` — отслеживать прогресс |
| `workerPath` | (опционально) | Путь к `worker.js`, если нужен кастомный worker |

### Особенности работы

1. **WASM загрузка**: при первом запуске загружает WASM core + traineddata (~5-10 секунд). Последующие запуски быстрее.
2. **Качество**: достаточное для извлечения текста со скриншотов, постов, презентаций. Для сканов низкого качества — предварительно обработать (контраст, ч/б).
3. **Точность**: на скриншотах с чётким текстом — 90-95%. Зашумлённые изображения / нестандартные шрифты — 60-80%.
4. **Таймаут**: для больших изображений (4K+) может потребоваться > 30 секунд. Ставьте timeout=120.

### Если OCR не нужен, а нужно только описание изображения
Используй vision_analyze, если оно доступно (обычно через отдельный vision model). OCR через tesseract.js — когда нужно именно извлечь текст для дальнейшей работы.
