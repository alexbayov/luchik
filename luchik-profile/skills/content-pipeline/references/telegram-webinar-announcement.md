# Telegram Post-Анонсы для вебинаров «Лучи»

## Типы постов

### Тип 1 — Первый анонс (за 2-3 недели)
Цель: рассказать о вебинаре, собрать регистрации.

**Структура:**
```
Прехедер: дата и время (🗓)
Тема: жирным или заглавными

Привет!

Абзац — о чём вебинар, кто спикеры, формат.

На вебинаре обсудим:
— пункт 1 (с вопросительного слова: как/почему/что);
— пункт 2;
— пункт 3 (все пункты — с одной части речи).

👉 Кнопка: Зарегистрироваться

Блок про запись: «Если не успеете — пришлём запись и материалы».
Подпись: «До встречи!»
```

### Тип 2 — Пост-анонс / финальный анонс (за 1-3 дня до вебинара)
Цель: напомнить, дожать регистрации, дать детали.

**Структура (по reference — OCR пост-анонса Alter):**
```
||Spoiler: «Лучи» + партнёр||

Тема — жирным

🗓 Дата, 11:00 мск
🎫 Бесплатно

Привет!

Абзац про контекст: «Мы уже рассказывали, о чём будем говорить. А теперь — финальные детали.»

Абзац про формат: «Живой разговор без воды: HR BP + эксперты разберут кейсы и дадут инструменты».

Поговорим о том:
— как/где/почему (все с одной части речи, все согласуются с заголовком);
— ...

👉 Зарегистрироваться

Блок про запись.
До встречи! 🙌
```

### Тип 3 — Пост-благодарность (после вебинара)
Цель: сказать спасибо, раздать материалы (запись + презентация).

**Структура (по reference OCR):**
```
Spoiler: бренды

Тема вебинара

Дата и время   Бесплатно

Привет!

«Спасибо за интерес к вебинару „Тема“. Мы продуктивно и живо обсудили [кратко о чём].»

«Если хотите освежить в памяти — как и обещали, подготовили презентацию и запись.»

📺 Смотреть запись вебинара
📥 Скачать презентацию

«Спасибо, что были с нами!»
```

## Единые правила для всех типов

### Форматирование
- **Spoiler** (||текст||) — для строки с брендами вверху (не обязательно, если публикуется не в канале с топиками)
- **Жирный текст** — для темы вебинара
- Эмодзи в начале строк: 🗓 дата, 🎫 цена, 📺 запись, 📥 презентация, 👉 кнопка, 🙌 подпись
- Кнопка CTA: «Зарегистрироваться» (единственный вариант для пре-ивента), «Смотреть запись» / «Скачать презентацию» (для пост-ивента)
- Блок про запись — всегда есть, даже в первом анонсе. Снимает страх пропустить.

### Тон и язык
- Начинается с «Привет!» (неформально, тепло)
- Короткие абзацы (2-3 предложения максимум)
- Списки с тире, пункты с одной части речи
- Без канцелярита, без сложных конструкций
- Бренд-лексика «Лучи» — не чаще одного раза, уместно
- Подпись: «До встречи!» / «До встречи на эфире!»

### Адаптация из референса
Если пользователь прислал скриншот предыдущего поста как референс:
1. OCR скриншот (см. `references/image-ocr-tesseractjs.md`)
2. Определи тип поста (анонс / пост-анонс / пост-благодарность)
3. Скопируй структуру, формат эмодзи, длину абзацев
4. Адаптируй содержание под текущий вебинар (тема, дата, спикеры, программа)
5. Если референс — пост-благодарность, а вебинар ещё не прошёл → напиши финальный анонс (Тип 2)
