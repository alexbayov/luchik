# PROSE-ENGINE

One-line mandate: Produce writing that feels authored by a specific human, not generated by a committee.

The root problem this skill solves: most models default to competent mediocrity — no errors, no soul, no reason to keep reading. This skill replaces implicit style with explicit mechanical rules that any model can execute.

## 0. ACTIVATION PROTOCOL

When this skill fires, ask ONE question if not already answered:

**"What are we writing, and who reads it?"**

Format: `[type] / [topic] / [audience]`
Example: blog post / async communication in remote teams / senior engineers

Then set your Writing Profile (internal, not shown to user):

```
TYPE:      [article | post | doc | essay | story | thread]
LANGUAGE:  [RU | EN | mixed]
AUDIENCE:  [fill from answer]
  - what they already know:
  - what they want to feel after reading:
  - what jargon is safe:
TONE:      [infer from audience: technical / conversational / authoritative / playful]
LENGTH:    [infer from type: post ≈600w, article ≈1200–2000w, doc = as needed]
```

Do not proceed until Writing Profile is set.

## 1. INTEGRATED PIPELINE (5 STAGES)

If content-pipeline skill is loaded — defer to its gate logic. If not — use this condensed version.

### Stage 1 — BRIEF (do not skip)

Before writing a single word, answer all of these internally:

```
CORE CLAIM:    One sentence. What is the single thing this piece argues/shows?
               If you can't write it, you're not ready to write.
ENTRY HOOK:    What specific scene/fact/question opens this?
               NOT: "In today's world..." or "Have you ever wondered..."
               YES: A scene, a number, a contradiction, a confession.
STRUCTURAL ARC:
  - Opening tension or curiosity gap
  - 2–4 body moves (each must earn the next)
  - Closing: forward momentum or earned reframe (NEVER a question)
WHAT TO OMIT:  List 2–3 things you will NOT include (scope discipline).
```

### Stage 2 — DRAFT (soul-first, not polish-first)

Write fast, write hot. Do not self-edit during this stage.

Apply **SOUL INJECTION CHECKLIST** during drafting (not after):

- [ ] Opening paragraph: contains at least one sensory detail (smell/visual/texture/sound)
- [ ] Concrete comparisons: every abstraction paired with a specific ("not large — copper-coin sized")
- [ ] One structural surprise: something the reader didn't expect in that position
- [ ] First-person moment: at least one genuine "I" statement with a real opinion
- [ ] One mess: a hesitation, a caveat, a "to be honest" — signals human thought
- [ ] Specific feelings: not "it was interesting" — "it made me reread the paragraph twice"

Rhythm seeding during draft: After every 3–4 sentences of normal length, insert one that is ≤8 words. Do not explain it. Just do it.

### Stage 3 — STRUCTURAL REVIEW

Check arc, not sentences. Ask:

1. Does the opening earn the reader's attention in ≤30 words?
2. Does each section need to follow the previous, or could you shuffle them? (If shuffleable → logic is broken. Fix connective tissue.)
3. Does the ending land somewhere new, or just restate the intro?
4. Is there exactly one main claim per paragraph?

Fix structural issues now. Do not proceed with broken structure.

### Stage 4 — REVISION (3 mandatory passes — see Section 4)

Full revision methodology. Do not compress.

### Stage 5 — QUALITY GATE

Before delivering output, run quantitative checks (Section 6). If any check fails — fix and re-check.

|---------|-------------|
| данный / данная / данное | этот / эта / это или конкретное слово |
| осуществлять / осуществить | делать / провести / выполнить |

| на сегодняшний день | сегодня |

| с целью | чтобы |
| в целях | для |
| посредством | через / с помощью |
| в случае если | если |
| за счёт того, что | потому что / так как |

### AI-Сигналы (Model Tells)

| Pattern | Проблема |
|---------|----------|
| Важно отметить | Если важно — само покажет. Убрать. |
| Следует отметить | То же. |
| Необходимо подчеркнуть | То же. |
| Стоит отметить | То же. |
| Нельзя не отметить | Двойное отрицание — слабо. |

| В заключение | Читатель видит конец. Не говорить. |
| В целом | Слишком размыто. Конкретизировать. |
| Безусловно | Пустой усилитель. Убрать. |
| Очевидно, что | Если очевидно — зачем писать? |
| Более того (без реального усиления) | Ставить только при настоящем усилении. |
| Помимо этого | Заменить конкретной связкой. |
| Что касается [темы] | Слабый переход. Переструктурировать. |
| Говоря о [теме] | То же. |
| Как уже было сказано | Если нужно повторить — переформулировать. |
| Позволяет (3+ раз в тексте) | AI-маркер. Варьировать. |
| Играет важную роль | Покажи, как именно. |
| Ключевым аспектом является | Покажи, почему ключевой. |
| В современном мире | Дать конкретный год/контекст или убрать. |
| Hypophora: Почему это важно? Потому что... | AI-шаблон. Убрать вопрос, оставить ответ. |

### Пассивный Залог

Russian uses reflexive verbs (-ся) as passive proxy. Watch for:
осуществляется / проводится / выполняется / реализуется / рассматривается

Target: ≤20% предложений с возвратными глаголами в роли пассива.

### Номинализации

| Слабо | Сильно |
|-------|--------|
| осуществление проверки | проверить |
| проведение анализа | проанализировать |
| принятие решения | решить |
| оказание поддержки | поддержать |
| обеспечение доступа | дать доступ |

### Структурные Паттерны

- Трёхчастный список без нарратива: три пункта — AI-дефолт. Если список, объяснить почему именно эти три.
- Зеркальный финал: заключение пересказывает введение — запрещено.
- "С одной стороны... С другой стороны..." без реального противоречия — клише.

## 3. ENGLISH AI-SLOP PATTERNS (29 patterns)

### Hedging Phrases (Delete entirely)

It's worth noting · It's important to mention · It goes without saying · Needless to say · As you might expect · Obviously · Clearly · Certainly

### Filler Transitions

Furthermore · Moreover · Additionally · In conclusion · To summarize · Last but not least · At the end of the day

### Structure Anti-Patterns

- Hypophora: What makes this special? It's the way... → remove the question, keep the answer
- "It's not X, it's Y": weak contrast. Show the difference instead.
- Three-part lists as default: earn each item
- Opening with "In today's..." / "Have you ever wondered..."
- Ending with a question: final sentences must close, not open

### Tone Tells

Delve into · Elevate · Seamlessly · Leverage · Unleash · Game-changing · Transformative · Robust (in non-technical contexts)

## 4. REVISION METHODOLOGY (3 Mandatory Passes)

Do these passes in order. Each pass has a different focus level. Do not mix levels.

### Pass 1 — STRUCTURAL (top-down, 10,000ft)

1. Opening hook: does it create forward pull without cliché?
2. Remove any paragraph mentally — does the piece survive without it? If yes, the paragraph must add unique value or get cut.
3. Each paragraph: name its one job. Can't name it → restructure.
4. Transitions: logical (earned) or decorative (Moreover...)? Eliminate decorative.
5. Ending: arrives somewhere new? Not a summary, not a question.

Output: mark sections [STRUCTURAL: OK] or [FIX: reason].

### Pass 2 — PARAGRAPH (mid-level)

Per paragraph:

1. First sentence pulls you in (not "This section discusses...")
2. Last sentence propels forward (momentum, not full stop)
3. Sentence length variance: mix short (≤8w) / medium (9–20w) / long (21+w). No 3 consecutive same-category.
4. One concrete detail minimum: number, name, scene, smell, color, texture.
5. Flag every passive. Keep only where agent is genuinely unknown.
6. AI-slop scan: run Section 2 (RU) or Section 3 (EN) on each paragraph.

### Pass 3 — SENTENCE (ground level)

1. Cut every word that doesn't add meaning: very / quite / rather / довольно / весьма / достаточно
2. Replace noun-verb combos with strong single verbs: made a decision → decided, провёл анализ → проанализировал
3. Every abstract adjective: what does it look like in action? Write that instead.
4. Read aloud (simulate). Where you stumble — fix.
5. First and last sentences of the entire piece: read them together. Do they frame a world?

## 5. CLAUDE'S WRITING PRINCIPLES (10 Rules)

### Rule 1 — Sensory Density in Openings

Every opening paragraph: at least two sensory channels (smell / visual / texture / sound / taste).
❌ "Remote work changed how teams collaborate."
✅ "The Slack ping came at 2 AM. I heard it through the wall."

### Rule 2 — Concrete Comparisons Only

❌ "a large crowd" → ✅ "four hundred people, more than the building held at graduation"
❌ "nearby" → ✅ "twenty feet away, close enough to read his name tag"
❌ "expensive" → ✅ "it cost what I spent on groceries in a month"

### Rule 3 — No Hypophora

❌ "Why does this matter? Because..."
✅ State the point directly with evidence.

### Rule 4 — No "It's Not X, But Y"

❌ "It's not about the money, it's about the principle."
✅ State what it IS, with specifics that make the contrast implicit.

### Rule 5 — Sentence Structure Variance

No more than 2 consecutive sentences starting with the same grammatical pattern. Rotate: Subject-first / Verb-first / Clause-first / Fragment.

### Rule 6 — Rhythm: Short-Long-Short

After any sequence of 3+ medium sentences (10–18w), insert one short sentence (≤8w). The short sentence carries the weight. It lands. Like that.

### Rule 7 — Active Voice as Default

Passive permitted only when: (a) agent genuinely unknown, (b) patient is more important, (c) deliberate distancing effect. Everything else → rewrite active.

### Rule 8 — Show Don't Tell

For every abstract quality claim: "What does this look like in action?" → translate to scene, action, or measurement.
❌ "She was brilliant."
✅ "She found the bug in forty seconds. The bug the senior team had chased for a week."

### Rule 9 — Endings: Forward Momentum Only

Final sentences must NOT: summarize, ask a question, use "in conclusion."
Final sentences must: land somewhere new, give something to do/think/feel, or close the loop on the opening image (only if earned).

### Rule 10 — The Specific Feeling

❌ "I felt confused."
✅ "I read it three times. Each time I understood it less."

| Avg sentence length | 12–18 words | 14–20 words |

Flesch-Kincaid Proxy (RU):
- Simple: avg ≤12w, avg word ≤5 chars — general audience
- Standard: 13–18w, 5–7 chars — educated readers
- Dense: 19+w or 7+ chars — specialists only

Match to audience model. Blog = Standard or Simple.

## 7. AUDIENCE MODELING

Fill before Stage 2. Writing without an audience model produces generic text.

```
AUDIENCE MODEL:
  Label:             [e.g., "senior backend engineers at a startup"]
  What they know:    [e.g., "distributed systems; don't know ML"]
  What they believe: [e.g., "microservices > monoliths"]
  What they want:    [e.g., "practical answer fast, no hand-holding"]
  What they fear:    [e.g., "theory that doesn't apply to their stack"]
  Safe vocabulary:   [e.g., "CAP theorem — yes; backpropagation — no"]
  Reading context:   [e.g., "Slack on mobile during standup break"]
```

Jargon rule: if in "Safe vocabulary" — use without definition. If not — define once, tersely. Never define what the audience already knows.

## 8. SOUL INJECTION PROTOCOL

A piece has soul when it reflects:

- A specific mind — a particular way of seeing, not the consensus view
- Real opinions — stated directly, not hedged into non-existence
- Earned complexity — complication that doesn't resolve cleanly, acknowledged
- Temporal texture — written now, about something specific
- One thing the writer noticed that others miss

### Soul Injection Checklist (embed in Draft)

- [ ] Opinion statement: one place saying what you actually think, using "I" or declarative. Not "some argue that..." — "I think X because Y."
- [ ] Unpopular take or caveat: one place where the piece complicates its own argument.
- [ ] Specific scene or micro-story: one paragraph that reads like memoir or journalism.
- [ ] Something noticed: one inference from the specific experience, not a Wikipedia fact.
- [ ] Rhythm moment: three sentences you could hear spoken aloud at a particular pace.

### RU-specific antidotes

Russian AI text tends toward: nominalizations, impersonal constructions (следует, можно сказать), no first-person, uniform formal register.

Fix with:

- Use я at least once per 600 words in opinion contexts
- Allow one register shift (colloquial phrase in formal piece)
- Use em-dash aside or parenthetical for a personal note
- Allow one sentence that deliberately breaks the dominant syntax pattern
