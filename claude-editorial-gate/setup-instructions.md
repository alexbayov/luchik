# Как настроить Editorial Gate в Claude — инструкция для Kate

## Что понадобится

1. Аккаунт Claude (Pro или Team) — нужен доступ к **Projects**
2. Три файла из этого пакета:
   - `custom-instructions.txt` → вставляешь в поле **Custom Instructions**
   - `knowledge-editorial-policy.md` → загружаешь в **Knowledge Base**
   - `knowledge-editorial-audit.md` → загружаешь в **Knowledge Base**

---

## Пошаговая настройка

### Шаг 1: Создай Project

1. Открой Claude → левое меню → **Projects**
2. Нажми **Create Project**
3. Название: `Лучи — Editorial Gate`
4. Описание: `Автоматическая проверка текстов по редполитике «Лучи»`

### Шаг 2: Загрузи Knowledge-файлы

1. Внутри проекта открой раздел **Knowledge Base**
2. Нажми **Add content** → **Upload file**
3. Загрузи `knowledge-editorial-policy.md`
4. Повтори для `knowledge-editorial-audit.md`
5. Убедись, что оба файла появились в списке

### Шаг 3: Вставь Custom Instructions

1. Открой раздел **Custom Instructions** (или Project Instructions)
2. Скопируй всё содержимое `custom-instructions.txt`
3. Вставь в поле
4. Сохрани

### Шаг 4: Выбери модель

В настройках проекта выбери **Claude Sonnet 4** или **Claude Opus 4** — они лучше всего работают с инструкциями и форматами.

---

## Как использовать

### Вариант 1: Проверка готового текста

```
Проверь этот текст:

[вставляешь текст письма/поста/скрипта]
```

Claude выдаст отчёт в формате:
- 🔴 Критические → конкретная фраза + причина + готовая замена
- 🟡 Рекомендации
- 🟢 Пройдено
- 📝 Итог: X/10

### Вариант 2: Проверка + правки

```
Проверь и сразу дай исправленную версию:

[вставляешь текст]
```

### Вариант 3: Проверка слайдов

```
Проверь структуру этой презентации (вставь текст по слайдам):

Слайд 1: [текст]
Слайд 2: [текст]
...
```

Claude прогонит аудит презентаций по чек-листу (нарратив, плотность, CTA, данные).

### Вариант 4: Быстрая проверка

```
Быстро проверь:
[текст]
```

Claude ответит на 4 вопроса: красные флаги? понятно? что почувствует клиент? ссылки?

## Что Claude МОЖЕТ делать

✅ Проверять текст по всем чек-листам редполитики
✅ Находить канцелярит, негатив, бренд-перебор
✅ Давать готовые замены (не просто «тут плохо», а «напиши так»)
✅ Проверять структуру (суть в начале, абзацы, следующий шаг)
✅ Детектить AI slop (29 паттернов)
✅ Аудит слайдов (нарратив, плотность, CTA, данные)
✅ Оценивать по 10-балльной шкале
✅ Работать с русским языком

## Что Claude НЕ МОЖЕТ делать

❌ Проверять ссылки (не умеет открывать URL)
❌ Искать источники и факты (нет веб-поиска в базовом режиме)
❌ Создавать .docx файлы
❌ Работать с Google Docs напрямую
❌ Запускать cron-задачи

## Тест после настройки

Скопируй этот текст и отправь в Claude Project:

```
Проверь этот текст:

Добрый день! Информируем вас, что в соответствии с изменениями в регламенте компании, с 1 сентября осуществляется пролонгация ваших договоров страхования. Вам необходимо предоставить полный пакет документов для осуществления калькуляции. Ознакомьтесь с подробностями на сайте.
```

**Ожидаемый результат:**
- 🔴 Канцелярит: «информируем вас» → «сообщаем»
- 🔴 Канцелярит: «в соответствии с» → «по правилам»
- 🔴 Канцелярит: «осуществляется пролонгация» → «продлеваем договоры»
- 🔴 Канцелярит: «вам необходимо предоставить» → «подскажу, какие документы понадобятся»
- 🔴 Канцелярит: «осуществление калькуляции» → «рассчитать стоимость»
- 🔴 Отсылка к сайту без объяснений: «ознакомьтесь на сайте»
- 🔴 Негатив: «вам необходимо» → избыточное долженствование
- 📝 Итог: 2/10 — переработать полностью

## Советы

1. **Группируй тексты** — если нужно проверить 3 письма, отправь их одним сообщением с разделителями. Claude проверит все и выдаст 3 отчёта.
2. **Уточняй сегмент** — если не указать сегмент, Claude определит сам, но лучше писать: «Это для B2B2C, email».
3. **Проси правки** — после отчёта скажи «исправь» — Claude выдаст готовый текст с заменами.
4. **Не загружай ссылки** — Claude не проверит URL. Проверяй ссылки отдельно (в Hermes или вручную).
5. **Добавляй новые кейсы** — если находишь повторяющиеся ошибки, допиши их в knowledge-файлы и перезалей.

---

## Если Claude не понимает редполитику

Если Claude пропускает канцелярит или неправильно оценивает:

1. Добавь в Custom Instructions строку: `Канцелярит — критический флаг. Любое совпадение со словарём замен = 🔴. Без исключений.`
2. Поставь оценку за пропуск канцелярита = 0/10
3. Переопубликуй Project — Claude подхватит обновлённые инструкции
